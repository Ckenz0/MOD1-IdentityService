# Diagramas históricos do Módulo 1

Este arquivo preserva os diagramas produzidos para Identidade 0.4.0,
Projetos 0.5.0, Backlog 0.4.0 e Frontend 0.5.0. Foram publicados no repositório
em 22/11/2026, sem alterar o conteúdo original das figuras.

As expressões “arquitetura final”, “IA pendente”, “revisão externa pendente” e
“remetente de teste” presentes nos materiais se referem àquela entrega. Eles
não representam o estado das integrações posteriores de Gemini, Resend e dos
Módulos 4, 5 e 6, nem comprovam disponibilidade atual em produção. A troca de
provedor de banco em discussão não foi executada.

Consulte a [arquitetura atual da Identidade](../../architecture.md) e o
[guia de integração entre módulos](https://github.com/Ckenz0/MOD1-WebFrontend/blob/main/docs/integracao-outros-modulos.md)
para os contratos e o estado operacional documentados.
